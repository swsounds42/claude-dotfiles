# Design System References

58 production design systems available on demand via `npx getdesign@latest add <name>`. Each delivers ~300 lines of exact tokens: colors, typography, shadows, components, spacing, layout rules.

## How to Use

When building UI inspired by a specific brand:
1. Run `npx getdesign@latest add <name>` to fetch the DESIGN.md
2. Read the fetched DESIGN.md for exact tokens (hex codes, font specs, shadow formulas)
3. Apply UI/UX Pro Max principles for accessibility, interaction, and responsive behavior
4. The DESIGN.md provides the visual language; UI/UX Pro Max provides the quality guardrails
